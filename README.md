# HR-Attrition-ML

This project was developed as my **Final Project for Year 1 Semester 2** in the **Data Science and Engineering** program at the Royal University of Phnom Penh, under the course **Introduction to Machine Learning**.

The objective of this project is to analyze employee data and build a predictive machine learning model to identify employees who are at risk of leaving the company. This solution supports data-driven decision-making for improving employee retention.

## Objectives
- Develop a machine learning model to predict employee attrition  
- Analyze key factors influencing employee turnover  
- Apply a complete machine learning workflow

---

## Dataset
The dataset used is **HR Analytics: Employee Attrition**, which includes:
- Job Satisfaction  
- Work-Life Balance  
- Salary  
- Years at Company  
- Department & Job Role  
- Performance Metrics

## Methodology

### 1. Data Preprocessing
- Data cleaning and handling missing values  
- Encoding categorical variables  
- Feature scaling  

### 2. Exploratory Data Analysis (EDA)
- Data visualization  
- Correlation analysis  
- Pattern identification  

### 3. Model Development
- Logistic Regression  
- Decision Tree  
- Random Forest  

### 4. Model Evaluation
- Accuracy  
- Confusion Matrix  
- Precision, Recall, F1-score  

---

## Key Insights
- Low job satisfaction increases attrition risk  
- Poor work-life balance impacts retention  
- Salary and tenure are important factors
